# 🛒 Retail Store Inventory & Sales Database

## 📌 Project Overview

This project focuses on designing and analyzing a relational
database for a retail store using MySQL.

The database manages customers, products, inventory, orders,
and order items.

## 🎯 Problem Statement

A retail store needs a structured database to manage sales,
inventory, customer information, and product data.

The objective is to design a relational database and use SQL
queries to analyze sales performance, inventory levels,
customer purchasing behavior, and identify high-value customers.

## 🗄️ Database Tables

The database contains five main tables:

- Customers
- Products
- Inventory
- Orders
- Order_Items

## 🔗 Database Relationships

- Customers → Orders
- Orders → Order_Items
- Products → Order_Items
- Products → Inventory

## 🛠️ SQL Concepts Used

- SELECT
- WHERE
- IN
- ORDER BY
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- SUM()
- COUNT()
- AVG()
- Primary Keys
- Foreign Keys
- Subqueries

## ⭐ High-Value Customer Analysis

Customers spending more than ₹50,000 on completed orders
are classified as high-value customers.
